# "Who was doing slides 8–12?" — AI-illustrated shot list

Characters and key frames are generated with Canva's image generator, using the cast sheets as
references so faces and outfits stay consistent. Remotion then animates them (camera moves,
parallax layers, phone glow, expression swaps) and adds voices, captions and sound.

Style line used in every prompt:
"Single frame from a hand-drawn 2D animated short film, same art style and character design as the
reference sheet (thin ink lines, flat cel colours, soft painted lighting, detailed lived-in
background) … Vertical composition, no text."
